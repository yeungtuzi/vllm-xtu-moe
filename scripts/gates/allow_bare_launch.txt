# ── 一、proc.sh spawn 的【载荷脚本】(按设计豁免,不是债)─────────────────────
#    这些脚本正是 `proc.sh spawn <name> bash scripts/serve_*.sh` 里的那个 payload:
#    它内部用 nohup/setsid 把【真正的 python 服务】交出去,然后自己退出 ——
#    bringup 注释已记录该模型("proc.sh 的 PID 文件记的是包装脚本,真服务 PID 靠端口派生 + adopt 认领")。
#    ⇒ 让载荷脚本再去调 proc.sh spawn 会变成"嵌套管理",且丢失 adopt 认领语义 ✗
scripts/serve_mainline.sh	载荷脚本:内部 nohup 把真服务交出去后退出;PID 由端口派生 + proc.sh adopt 认领(bringup 注释已记录)
scripts/serve_glm53_mainline.sh	载荷脚本:同上(serve_* 家族统一模型)
